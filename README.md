## Mettre le site en ligne avec GitHub Pages

1. Sur github.com, cliquer sur **New repository**, nommer le dépôt (ex. `netpro-multiservices`), le laisser **Public**, puis **Create repository**.
2. Cliquer sur **uploading an existing file**, puis glisser **tout le contenu** du dossier `netpro-site` (`index.html`, `style.css`, `script.js`, `README.md` et le dossier `assets`). Cliquer **Commit changes**.
3. Aller dans **Settings → Pages**. Dans *Branch*, choisir `main` et `/ (root)`, puis **Save**.
4. Après 1 à 2 minutes, le site est disponible à l'adresse :
   `https://VOTRE-PSEUDO.github.io/netpro-multiservices/`

## Fichiers
- `index.html` – contenu de la page
- `style.css` – mise en forme
- `script.js` – menu mobile, animations, formulaire de devis (ouvre la messagerie)
- `assets/` – logo
